# Football Event-Data Visualizations in R

This project uses R to create football event-data visualizations, including shot maps, pass maps, and cross-location maps.

## Project Overview

The project analyzes football event coordinates and transforms them into pitch dimensions to visualize player actions. It includes visualizations for:

- Cristiano Ronaldo shot maps
- Luka Modric pass maps
- Trent Alexander-Arnold cross-location maps
- Marcelo cross-location maps

The visualizations use color and hover logic to distinguish goals, shot accuracy, pass accuracy, and cross accuracy.

## Tools and Libraries

- R
- sf
- dplyr
- readr
- Plotly

## Features

- Football pitch coordinate transformation
- Shot-location visualization
- Pass-location visualization
- Cross-location visualization
- Interactive Plotly hover information
- Accuracy-based visual encoding
